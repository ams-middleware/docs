# Reportes

## Pasos

1. **Filtre el listado** hasta que muestre exactamente lo que quiere exportar. Ver
   [Filtrado avanzado](../comunes/filtrado-avanzado.md).
2. En el menú de tres puntos (⁝) del toolbar, elija **Generar archivo**.
3. Póngale un **nombre** y confirme.
4. El archivo se genera en segundo plano. Cuando el proceso figure **Completado**, descárguelo.

<figure><img src="../.gitbook/assets/image (53).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
💡 Póngale un nombre que se entienda dentro de un mes: `ordenes-abril-canal-ML` sirve; `reporte3` no.
{% endhint %}

{% hint style="warning" %}
⚠️ Se exporta **todo lo filtrado**, no la página en pantalla. Si no filtró, se lleva el listado
entero, y eso en catálogos grandes tarda.
{% endhint %}

El seguimiento y la descarga están en [Gestión masiva](../operativa/cargas-masivas.md); el
comportamiento general, en [Procesos en segundo plano](../comunes/procesos.md).
