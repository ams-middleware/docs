# Tiendas

Una **tienda** agrupa su operación: sus órdenes, sus productos, sus conectores y sus reportes. Si
maneja varias marcas o varios países, cada uno puede ser una tienda.

{% hint style="info" %}
📸 **Captura pendiente — `conf-tiendas-01`** · PNG

Listado de Tiendas y, al lado, el selector de tienda de la barra superior desplegado.
{% endhint %}

## Trabajar con varias

- La tienda activa se elige en la **barra superior** y se puede cambiar sin cerrar sesión.
- Todo lo que ve después —listados, reportes, filtros— pertenece a esa tienda.

{% hint style="danger" %}
🛑 Antes de crear una orden, publicar un producto o lanzar una carga masiva, **confirme la tienda
activa**. Una carga masiva en la tienda equivocada es de las cosas más difíciles de revertir.
{% endhint %}

{% hint style="info" %}
💡 ¿Necesita comparar entre tiendas? No cambie de una a otra: exporte cada una y compare en Excel o
Power BI. Ver [Datos y análisis](../datos-analisis/README.md).
{% endhint %}

## Datos de la tienda

Nombre, moneda, zona horaria y datos fiscales. La moneda y la zona horaria afectan cómo se muestran
importes y fechas en toda la plataforma.

{% hint style="warning" %}
⚠️ Cambiar la moneda **no reconvierte** los importes ya cargados: solo cambia cómo se muestran.
{% endhint %}
