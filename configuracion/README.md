# ⚙️ Configuración

A diferencia de la operativa diaria, acá se cambian las reglas del juego. Un cambio en esta sección
afecta a todo lo que pase después.

| | |
|---|---|
| [Tiendas](tiendas.md) | Sus unidades de negocio y cómo se opera más de una. |
| [Workflow de órdenes](workflows.md) | El circuito que recorre cada orden. |
| [Reglas](reglas.md) | Automatismos: qué hacer cuando se cumple una condición. |
| [Tareas programadas](scheduler.md) | Qué corre solo y cada cuánto. |

{% hint style="warning" %}
⚠️ Los cambios de esta sección **no se aplican hacia atrás**. Las órdenes y publicaciones que ya
existen siguen con la configuración que tenían cuando se crearon.
{% endhint %}

{% hint style="info" %}
💡 La administración de la plataforma —usuarios, roles, atributos, integraciones— se hace desde el
**panel de administración**, que es otro sistema y tiene su propio manual.
{% endhint %}
