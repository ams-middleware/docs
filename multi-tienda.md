# Multi-Tienda

{% hint style="info" %}
El **EMW** está configurado por defecto para trabajar con múltiples tiendas simultáneamente. Para configurar nuevas tiendas, por favor [contacte a soporte](https://app.gitbook.com/u/SvK4k8Van9ObqOAT0tcYT4b4pbk2).
{% endhint %}

#### Proceso de Selección de Cliente y Tienda

1.  **Botón de Tienda:**

    * En la barra superior de la plataforma encontrará un botón con el icono ![](<.gitbook/assets/image (1) (1) (1).png>) que le permitirá acceder a la configuración de tiendas.

    <figure><img src=".gitbook/assets/image (1) (1) (1) (1).png" alt=""><figcaption></figcaption></figure>
2.  **Modal de Selección:**

    * Al hacer clic en el botón de "Tienda", se abrirá una ventana modal donde podrá realizar la configuración deseada.

    <figure><img src=".gitbook/assets/image (15).png" alt="" width="451"><figcaption></figcaption></figure>
3.  **Campos de Configuración:**

    * **Cliente:** Por defecto se muestra el cliente registrado en la plataforma. Si tiene varios clientes asociados a su usuario, puede cambiar entre ellos utilizando el menú desplegable.

    <div align="center" data-full-width="false"><figure><img src=".gitbook/assets/image (3) (1).png" alt=""><figcaption></figcaption></figure></div>

    * **Tienda:** Una vez seleccionado el cliente, el sistema mostrará las tiendas asociadas a ese cliente. Puede seleccionar una o varias tiendas para gestionar.

    <div data-full-width="false"><figure><img src=".gitbook/assets/image (4) (1).png" alt=""><figcaption></figcaption></figure></div>

    * **Botón Aplicar:** Después de seleccionar el cliente y las tiendas deseadas, haga clic en "**Aplicar**" para guardar la configuración.

<figure><img src=".gitbook/assets/image (16).png" alt=""><figcaption></figcaption></figure>
