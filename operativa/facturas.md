# 🧾 Facturas

El listado de comprobantes emitidos, con su orden asociada, su estado y su descarga.

{% hint style="info" %}
📸 **Captura pendiente — `fact-listado-01`** · PNG

Listado de Facturas con distintos estados. Tapar razones sociales y números reales.
{% endhint %}

## Qué puede hacer

- **Buscar** por número, orden o cliente. Ver [Listados](../comunes/listados.md).
- **Ver el detalle** y sus ítems.
- **Descargar** el comprobante.
- **Exportar** el listado para contabilidad. Ver
  [Importar y exportar](../comunes/importar-exportar.md).

{% hint style="warning" %}
⚠️ Un comprobante emitido **no se edita**. Si hay un error, el camino es una nota de crédito o un
comprobante nuevo, según su operación.
{% endhint %}

{% hint style="info" %}
💡 ¿Una orden completada no tiene factura? Revise el
[workflow](../configuracion/workflows.md): la emisión suele ser un paso del circuito y puede haber
quedado trabada.
{% endhint %}
