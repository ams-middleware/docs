# Códigos postales

La plataforma usa este padrón para validar direcciones y resolver zonas de envío. Si un código postal
no está, el envío no puede cotizarse.

## Buscar y corregir

1. Entre a **CRM → Códigos postales**.
2. Busque por código, localidad o provincia. Ver [Listados](../comunes/listados.md).
3. Edite o dé de alta lo que falte.
