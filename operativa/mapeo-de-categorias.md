# Mapeos de categoría

Su catálogo tiene sus propias categorías. Cada marketplace tiene el árbol suyo. El mapeo es el puente
entre las dos, y sin él **no se puede publicar**.

## Cómo se hace

1. Entre a **Productos → Mapeos de categoría**.
2. Elija el **canal**.
3. Busque su categoría y seleccione la del canal que le corresponde.
4. Guarde.

{% hint style="info" %}
📸 **Captura pendiente — `prod-mapeo-01`** · GIF (10 s)

Mapear una categoría propia contra la del canal: elegir conector, buscar la categoría destino en el
árbol y guardar.
{% endhint %}

{% hint style="warning" %}
⚠️ El mapeo es **por canal**. Mapear la categoría para Mercado Libre no la mapea para VTEX: cada
canal necesita el suyo.
{% endhint %}

{% hint style="info" %}
💡 Elija la categoría **más específica** que exista en el canal. Una categoría genérica hace que el
canal pida menos atributos, pero el producto se muestra peor en las búsquedas de los compradores.
{% endhint %}

## Cuando el canal cambia su árbol

Los marketplaces reorganizan categorías cada tanto. Si empiezan a fallar publicaciones que antes
funcionaban con un error de categoría, el mapeo apunta a una categoría que ya no existe: rehágalo.
