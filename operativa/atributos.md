# Valores de atributos

Usted carga **Rojo**. Un marketplace espera `RED`, otro un código numérico. Esta pantalla guarda esa
traducción una vez y se aplica sola en cada publicación.

## Cómo se carga

1. Entre a **Productos → Valores de atributos**.
2. Elija el **atributo** (por ejemplo, Color).
3. Para cada valor suyo, indique el valor equivalente **en cada canal**.
4. Guarde.

{% hint style="warning" %}
⚠️ Un valor **sin traducción** para un canal hace que el canal rechace el producto al publicarlo. Es
la causa número uno de rechazos.
{% endhint %}

{% hint style="info" %}
💡 No hace falta traducir todo de entrada. Traduzca los atributos de los productos que va a publicar
y complete el resto a medida que aparezcan rechazos.
{% endhint %}

## Qué atributos participan

Qué atributos se le piden a un producto lo define su **categoría**, y si son obligatorios lo define
la categoría o el propio canal. Si un atributo no aparece, revise la categoría del producto en
[Crear y editar](productos/editar.md).
