# 🏷️ Productos

El catálogo vive una sola vez acá y desde acá se publica en cada canal. Cambia el precio una vez y
sale a todos lados.

## Base y simple

| | |
|---|---|
| **Producto base** | El "padre": la información común (nombre, descripción, categoría). Agrupa variantes. |
| **Producto simple** | Lo que efectivamente se vende y tiene stock: un talle y color concretos. |

{% hint style="info" %}
💡 Una remera con 3 talles y 2 colores es **un producto base y seis productos simples**. El stock se
lleva en los simples; la descripción, en el base.
{% endhint %}
