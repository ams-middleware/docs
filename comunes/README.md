# 🧭 Lo que se repite en todas las pantallas

Órdenes, Productos, Clientes, Facturas: todos los listados de la plataforma se manejan igual. En vez
de repetirlo en cada módulo, está explicado una sola vez en estas páginas.

| Página | Le sirve para |
|---|---|
| [Listados](listados.md) | Buscar, ordenar columnas, elegir cuántos registros ver, refrescar. |
| [Filtrado avanzado](filtrado-avanzado.md) | Cruzar varios criterios y guardar el filtro para reusarlo. |
| [Acciones sobre una fila](acciones-fila.md) | Ver, editar, duplicar o eliminar un registro. |
| [Acciones masivas](acciones-masivas.md) | Hacer lo mismo sobre muchos registros a la vez. |
| [Importar y exportar](importar-exportar.md) | Sacar datos a Excel o cargarlos desde un archivo. |
| [Procesos en segundo plano](procesos.md) | Entender qué pasó con una sincronización o una carga. |

{% hint style="info" %}
💡 Si en un módulo algo se comporta distinto a lo que dice acá, la página de ese módulo lo aclara.
Las excepciones están señaladas donde corresponde.
{% endhint %}
