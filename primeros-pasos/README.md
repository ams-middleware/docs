# 🚀 Primeros pasos

Tres páginas cortas y ya puede operar.

1. **[Ingresar por primera vez](acceso.md)** — activar el usuario, la contraseña, elegir tienda.
2. **[La pantalla en un minuto](la-pantalla.md)** — qué es cada parte de la interfaz.
3. **[Glosario](glosario.md)** — orden, conector, integración, SKU. Vale la pena mirarlo.

{% hint style="info" %}
💡 Después de esto, lea **[Lo que se repite en todas las pantallas](../comunes/README.md)**. Es el
80% del uso diario: buscar, filtrar, exportar y acciones masivas funcionan igual en todos los
módulos.
{% endhint %}
